# TruthLens AI Frontend Modules

The frontend of TruthLens AI is composed of:
- **Bootstrap 5 UI**: Glassmorphic, modern responsive layout with dark blue background tokens.
- **Dynamic JavaScript (`static/js/main.js`)**: Real-time AJAX API prediction engine, password toggling, and history item deletion.
- **Visualization (`static/js/dashboard_charts.js`)**: Interactive Chart.js charts for user and admin statistics.
- **Jinja2 Templates (`templates/`)**: Modular HTML5 templates extending `base.html`.
